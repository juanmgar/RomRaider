1. Introducción

ROM Raider es una aplicación de escritorio para gestionar colecciones de ROMs de videojuegos clásicos.

  • Gestionar plataformas
  • Añadir, editar y eliminar ROMs
  • Escanear carpetas y organizar ROMs automáticamente
  • Actualizar metadatos desde RAWG.io
  • Sincronizar con Supabase
  • Consultar estadísticas
  • Importar/exportar en XML

2. Inicio e inicio de sesión

2.1 Inicio de la aplicación

Al ejecutar la aplicación por primera vez se crea automáticamente:

  • La base de datos local H2 en ~/.romraider
  • Un conjunto de plataformas por defecto

2.2 Inicio de sesión

Puedes:

  • Iniciar sesión con email y contraseña
  • Registrarte
  • Usar el modo Offline

En modo Offline:

  • La base de datos local se reinicia
  • No se puede sincronizar con la nube
  • Se trabaja solo con XML

3. Pantalla principal

La pantalla principal se divide en:

  • Plataformas: lista y botones de gestión.
  • ROMs: lista filtrable por texto.
  • Detalle: descripción, imagen, favoritos, jugado.

Además incluye:

  • Menú File / View / Settings / Help
  • Botón Sync
  • Usuario actual o modo Offline

7. Escaneo de carpetas locales

Permite analizar una carpeta y detectar ROMs automáticamente.

Proceso

  1. Selecciona una carpeta.
  2. ROM Raider detecta las extensiones compatibles.
  3. Mueve cada archivo a la carpeta destino definida por la plataforma dentro de:
    ~/ruta-configurada-en-preferencias/PLATAFORMA/
  4. Si está activada la actualización automática:
    • Consulta RAWG.io
    • Rellena descripción e imagen

8. Sincronización con la nube

8.1 Requisitos

  • Usuario autenticado
  • Conexión Internet

8.2 Lógica real de sincronización

  • Primera sincronización o cambio de usuario: se descarga todo y se reconstruye la base local.
  • Remoto más reciente: se descarga la colección remota.
  • Local más reciente: se sube la colección local (solo si pertenece al mismo usuario).
  • Base local vacía: se sube o sincroniza según corresponda.
  • Sin cambios: no se realiza ninguna acción.

12. Preferencias

12.1 Cambio de idioma

ROM Raider permite seleccionar el idioma de la interfaz. Los idiomas dependen de los archivos incluidos en el paquete /i18n.

12.2 Ruta por defecto para ROMs

Define dónde se almacenan las ROMs tras el escaneo automático.

12.3 Actualización automática desde RAWG.io

Si está activada, el escaneo rellenará automáticamente la descripción e imagen de las ROMs detectadas.
