1. Introducción

Esta aplicación permite gestionar de forma sencilla una biblioteca de ROMs organizadas por plataformas (consolas, sistemas, emuladores, etc.). Desde la interfaz principal podrás:

  • Crear y editar plataformas.
  • Añadir, modificar y eliminar ROMs.
  • Marcar juegos como favoritos o jugados.
  • Sincronizar la información con servicios externos (por ejemplo, Supabase).
Nota: Este manual describe el uso básico de la aplicación. Algunas funciones avanzadas pueden no estar disponibles en todas las versiones.

2. Requisitos del sistema

  • Java 17 o superior instalado.
  • Sistema operativo Windows, Linux o macOS.
  • Conexión a Internet opcional para funciones online (por ejemplo, descarga de información desde APIs externas).

3. Primer inicio de la aplicación

  1. Ejecuta el archivo .jar o el lanzador correspondiente a tu sistema operativo.
  2. La primera vez se creará una base de datos local (por ejemplo, H2) con las tablas necesarias.
  3. Verás una ventana principal con la lista de plataformas a la izquierda y las ROMs a la derecha.

4. Gestión de plataformas

Las plataformas representan las consolas o sistemas (por ejemplo: Super Nintendo, PlayStation, MAME).

  • Añadir plataforma: usa el botón “Nueva plataforma” y rellena nombre, extensión de ROM, carpeta por defecto, etc.
  • Editar plataforma: selecciona una plataforma y haz clic en “Editar”.
  • Eliminar plataforma: selecciona la plataforma y haz clic en “Eliminar”. Si tiene ROMs asociadas, se te pedirá confirmación.

5. Gestión de ROMs

Las ROMs son los archivos de los juegos. Cada ROM está asociada a una plataforma.

5.1 Añadir una ROM

  1. Selecciona primero la plataforma en el panel correspondiente.
  2. Pulsa el botón “Añadir ROM”.
  3. En el formulario, introduce:
    • Título del juego.
    • Descripción opcional.
    • Ruta del archivo de la ROM (se puede seleccionar con un diálogo de fichero).
    • Opcionalmente, marca si es favorito o si ya está jugado.
  4. Confirma con “Guardar”.

5.2 Editar una ROM

  1. Selecciona la ROM en la tabla.
  2. Pulsa el botón “Editar ROM” o haz doble clic en la fila (si está configurado así).
  3. Modifica los campos necesarios.
  4. Guarda los cambios.

5.3 Abrir carpeta de la ROM

En la vista de detalle de una ROM puedes encontrar el botón “Abrir carpeta”.

  • Al pulsarlo, se abrirá el explorador de archivos del sistema directamente en la carpeta donde se encuentra la ROM.
  • Si la ruta no es válida, se mostrará un mensaje de error.

6. Copias de seguridad y sincronización

La aplicación puede ofrecer funciones de:

  • Copia de seguridad local: exportar la base de datos o los datos a un fichero.
  • Sincronización con Supabase u otros servicios: subir plataformas y ROMs para mantener una copia remota.

Para iniciar la sincronización, utiliza el menú “Herramientas → Sincronizar” (o el menú correspondiente en tu versión).

7. Preguntas frecuentes y problemas comunes

7.1 No se abre la aplicación

  • Comprueba que tienes instalada la versión correcta de Java.
  • Verifica que tu antivirus no esté bloqueando el ejecutable.

7.2 No puedo añadir ROMs

  • Asegúrate de haber creado al menos una plataforma.
  • Comprueba que la ruta del archivo de la ROM existe y es accesible.
